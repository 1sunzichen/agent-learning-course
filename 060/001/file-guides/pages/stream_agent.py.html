这样做的优点

用户更早看到文字；能理解文字流和工具调用如何衔接。

代价与局限

分片组装、多个工具索引和中途断流增加处理难度；流式不保证总耗时更短。

适用场景

聊天界面、需要即时反馈的问答。

不宜直接照搬

只需要最终结构化结果的后台批处理。

动手检验理解

观察一个工具参数是否分多次到达：参数完整前能否解析 JSON？
