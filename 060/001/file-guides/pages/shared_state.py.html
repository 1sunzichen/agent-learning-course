这样做的优点

数据汇聚在一个地方，容易观察变化。

代价与局限

锁只能保护读写，不自动保证业务依赖顺序；共享状态会增加耦合。

适用场景

单进程、明确写入顺序的小型协作。

不宜直接照搬

跨机器共享或复杂并发一致性需求。

动手检验理解

调换两个 worker 的执行顺序，观察读取是否得到缺失值。
