# 关卡 3-6 · 向量库选型对比

> 面试必考：Chroma / Milvus / FAISS 到底怎么选。先分清「库 vs 数据库」这个致命区别，再按规模选，两分钟讲明白。

---

## 一、先分清一个致命概念：FAISS 不是数据库

新手最容易栽的一点：把 FAISS 当成和 Milvus 平级的「向量数据库」去选。它们根本不是一类东西。

| | FAISS | Chroma | Milvus |
|---|---|---|---|
| 本质 | 库（library） | 嵌入式向量库 | 分布式向量数据库 |
| 部署 | `import faiss` 进程内用 | `import chromadb` / 单机服务 | 独立服务（Docker / K8s） |
| 持久化 | ❌ 要自己写磁盘序列化 | ✅ PersistentClient 落盘 | ✅ 原生持久化 |
| 元数据过滤 | ❌ 不支持（要自己另建倒排） | ✅ | ✅（标量 + 向量混合过滤） |
| 规模量级 | 内存级（千万～亿） | 几十万～百万 | 十亿级 |
| 分布式 / 高可用 | ❌ | ❌ | ✅ 分片、副本、水平扩容 |
| 索引算法 | IVF / HNSW / PQ 全都有 | 底层用 HNSW | IVF / HNSW / DiskANN / GPU 索引 |
| 典型场景 | 嵌入已有系统的「检索引擎」 | 原型、教程、小项目 | 生产级大规模 RAG |

一句话：**FAISS 是「引擎」不是「库房」**——它只负责「给你最快的最近邻搜索」，不管「数据怎么存、怎么查元数据、怎么多副本」，这些你都得自己搭。Chroma 和 Milvus 才是「带存储 + 带过滤 + 带管理」的完整产品。

---

## 二、三个候选的定位（面试 30 秒能讲）

1. **FAISS（Meta 出品）**：极致快、极简、零部署。你想要最高检索速度、而且已经在自己的系统里管好了元数据和持久化，就把 FAISS 嵌进去当内核。代价：过滤、持久化、高可用全都自己写。

2. **Chroma**：Python 原生、`pip install chromadb` 就能跑、自带 `where={"字段": "值"}` 元数据过滤。适合**原型验证 / 学习 / 百万级以内**。代价：单机，无分布式，规模上去要迁走。

3. **Milvus（Zilliz 开源）**：专为「十亿级 + 生产」设计，独立服务，支持标量+向量混合查询、分片、副本、流式写入。适合**上线后的生产系统**。代价：要运维一个服务（或买 Zilliz Cloud 托管），重。

---

## 三、选型决策树（拿到需求照着走）

按三个问题依次判断：

1. **数据量有多大？**
   - 几十万以内、还在做原型 → Chroma（零部署，今天就能跑）
   - 千万～十亿、要上线 → 跳到第 2 问

2. **要不要元数据过滤（「按标签/时间/作者先筛再检索」）？**
   - 不要、且你有自己的存储系统 → FAISS 嵌进去当内核
   - 要（混合查询）→ Milvus（标量+向量一把梭）

3. **要不要分布式 / 高可用 / 团队多人维护？**
   - 要 → Milvus（或托管版 Zilliz Cloud / Pinecone）
   - 不要、单机够用 → Chroma 撑到百万级，撑不住再迁 Milvus

记忆口诀：**「原型 Chroma，内核 FAISS，生产 Milvus」**。

---

## 四、别漏了另外几个（面试加分项）

面试官问到「除了这三个你还知道哪些」，能补这几个就赢了：

| 库 | 定位 | 一句话 |
|---|---|---|
| pgvector | Postgres 插件 | 向量存在关系库里，和业务数据 join，省一套系统 |
| Qdrant | Rust 写的向量库 | 快、过滤强，单机到分布式都行，Chroma 的进阶替代 |
| Weaviate | 图+向量混合 | 带 GraphQL、内置模块，适合知识图谱场景 |
| Pinecone / Zilliz Cloud | 托管 SaaS | 不想运维就交钱，按量付费 |

---

## 五、面试标准答法（背下来）

「向量存储分三类：FAISS 是库不是数据库，它只给最快的最近邻搜索，持久化和过滤得自己写，适合嵌进已有系统当引擎；Chroma 是嵌入式向量库，pip 装完就能用、自带元数据过滤，适合原型和百万级以内；Milvus 是分布式向量数据库，支持标量+向量混合查询、分片副本、十亿级，适合生产。

选型看三点：数据量（小→Chroma，大→Milvus）、要不要元数据过滤和分布式（不要且自有存储→FAISS 内核，要→Milvus）、想不想运维（不想→托管版 Pinecone/Zilliz Cloud）。一句话口诀：原型 Chroma，内核 FAISS，生产 Milvus。」
